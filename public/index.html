Privacy & limitations

Veil sends requested URLs to its backend, which retrieves pages and resources on your behalf. Destination sites see the backend IP address. Hosting providers may process request metadata, including IP addresses and URLs.

Veil does not promise anonymity. There are no advertising trackers or application browsing-history logs. Navigation history and private tabs exist only in memory. Bookmarks, search selection and backend settings are stored locally; access keys are kept in memory.

Website scripts never run on your device. Optional Chromium mode executes scripts remotely and returns a sanitised snapshot. Logins, POST forms, file uploads, WebSockets, streaming, DRM, downloads and persistent remote sessions are unsupported. Some sites block automated requests or rely on browser functionality that snapshots cannot preserve.

Links and supported GET forms navigate through Veil. Do not enter passwords, payment details or sensitive information. Private mode does not hide activity from the backend, destination, network or hosting provider.

Remote fetching is not direct website embedding. The isolated viewport contains backend-retrieved and processed content, not a destination URL iframe.
